# Архитектура Zoom Art Studio (v2.0)

## Концепт: «Фантомный холст» (Остановка времени)
Цель v2.0 — позволить пользователю рисовать сложные фигуры в «черновике» (невидимом для сервера Zoom), сохранять их в код и мгновенно воспроизводить на реальном холсте.

### Модуль 1: Перехватчик (Фантомный слой)
- **Механика:** При активации режима «Черновик» создаётся HTML-элемент `<canvas>`, который позиционируется абсолютно (`position: absolute; z-index: 99999; pointer-events: auto;`), накладываясь поверх зумовского `.upper-canvas`.
- **Эффект:** Все клики мыши теперь попадают в наш холст. Zoom перестаёт получать события `mousedown`/`mousemove`. «Время» для Zoom останавливается.
- **Отрисовка:** Мы используем стандартный Canvas 2D API (`ctx.lineTo`, `ctx.stroke`), чтобы пользователь видел, что он рисует на стекле.

### Модуль 2: Рекордер (Запись действий)
- Пока пользователь рисует на фантомном слое, мы записываем каждое действие.
- **Структура данных (JSON):**
  ```json
  {
    "version": 1,
    "shapes": [
      {
        "tool": "line",
        "color": "#ff0000",
        "points": [ { "x": 10, "y": 10 }, { "x": 50, "y": 50 } ]
      },
      {
        "tool": "rect",
        "color": "#000000",
        "points": [ { "x": 100, "y": 100 }, { "x": 200, "y": 200 } ]
      }
    ]
  }
  ```
- Для оптимизации мы можем не сохранять *каждый* пиксель при рисовании кривых линий, а использовать алгоритм Дугласа-Пекера для сглаживания (оставлять только ключевые точки перегиба).

### Модуль 3: Экспорт и Буфер обмена
- Записанный JSON массив можно сжать (Base64) и выдать пользователю в виде строки: `ZART:eyJ2ZXJza...`
- Пользователь может сохранять такие строки в текстовый файл и создавать свою личную библиотеку макросов (арт-заготовок).

### Модуль 4: Принтер (Auto-Drawer) - *Уже в Beta-версии!*
- Берёт готовую структуру JSON.
- **Авто-переключение UI:** Скрипт сам находит кнопки цвета (палитра) и кнопки инструмента (линия/прямоугольник) в интерфейсе Zoom и программно по ним кликает.
- **Отрисовка:** Эмулирует `MouseEvent` с задержкой 10-15 мс между штрихами.
- За 1 секунду скрипт может прокликать до 50 линий, что выглядит как магия для остальных участников конференции.

## План на следующий сеанс:
1. Интегрировать прозрачный Canvas-оверлей поверх Zoom.
2. Написать логику свободного рисования кистью по нашему оверлею.
3. Написать генератор JSON из нарисованных на оверлее штрихов.
4. Объединить это всё с нашим текущим Принтером.
