# ⚡ Zoom Web Tools (v1.9.0)

> Небольшой открытый набор инструментов для веб-версии Zoom (`app.zoom.us`). Добавляет функции, которых не хватает в браузере: завесу демонстрации экрана, быстрое управление ником и клонирование, спам реакций и руки, инспектор комнаты (прямая ссылка-приглашение, пароль и политики), копирование аватарок, мониторинг активности и **встроенный принтер рисунков** (Z-Art Studio).

Самый быстрый и удобный способ запустить скрипт за 30 секунд — вставить его напрямую в консоль разработчика браузера:

### Шаг 1: Зайдите в митинг через браузер
Откройте конференцию Zoom в любом браузере (Chrome, Edge, Firefox, Opera, Яндекс, Safari и др.) через веб-клиент.

### Шаг 2: Откройте консоль разработчика
* **Windows / Linux:** нажмите клавишу **`F12`** или комбинацию **`Ctrl + Shift + I`**.
* **macOS:** нажмите **`Cmd + Option + I`**.
* *Универсальный способ:* нажмите правой кнопкой мыши в любом месте страницы митинга → выберите пункт **«Просмотреть код»** (или **«Исследовать элемент»** / **Inspect**) → перейдите на вкладку **Console** (Консоль).

### Шаг 3: Снятие защиты от вставки (Self-XSS)
Современные браузеры блокируют первую вставку кода в консоль в целях безопасности:
* Введите в строку консоли слово **`allow pasting`** (на некоторых русскоязычных сборках: **`разрешить вставку`**) и нажмите **Enter**.
* Теперь блокировка снята, и браузер разрешит вставлять любой код.

### Шаг 4: Вставка скрипта
1. Откройте файл [**`zoom-tools.user.js`**](./zoom-tools.user.js) и скопируйте его содержимое целиком (`Ctrl+A`, `Ctrl+C`).
2. Вставьте скопированный код в консоль браузера (`Ctrl+V`) и нажмите **Enter**.
3. В правом нижнем углу страницы появится полупрозрачный виджет **Zoom Tools**.

> [!TIP]
> **Горячая перезагрузка:** скрипт можно вставлять в консоль повторно в любой момент без обновления страницы — старая версия виджета и таймеры автоматически завершаются, заменяясь новыми.

---

Если не хочется вставлять код вручную при каждом входе:
1. Установите расширение для скриптов, например [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. В панели расширения нажмите **«Создать новый скрипт»**.
3. Скопируйте и вставьте код из файла [**`zoom-tools.user.js`**](./zoom-tools.user.js).
4. Сохраните (`Ctrl+S`). Теперь виджет будет загружаться автоматически при входе в любую браузерную конференцию.

## 🛠 Обзор функций (просто и по делу)

* **🪟 Завеса демонстрации (`Alt + S`):** Заливает экран демонстрации сплошным черным прямоугольником. Есть опция подмены ника на время завесы — оригинальный ник запоминается и **автоматически возвращается** при снятии завесы через `Alt+D` или кнопку корзины.
  * **Разрешение от хоста:** Завеса рисуется через нативный слой аннотаций Zoom. Если организатор запретил комментирование — слой рисования физически не создаётся.
  * **Открытая панель рисования:** Тулбар аннотаций должен быть активирован (*«Настройки просмотра» → «Комментировать»*). Скрипт пытается открыть его сам.
  * **Таймаут неактивности:** Если демонстрация долго не двигается, Zoom усыпляет холст. Пошевелите мышкой по демонстрации для пробуждения.
* **🗑 Очистить слои (`Alt + D`):** В 1 клик нажимает внутреннюю корзину инструментов аннотации Zoom. Также восстанавливает оригинальный ник, если была активна завеса.
* **🌈 Радужная завеса:** Циклически меняет 10 ярких цветов заливки на холсте, создавая стробоскопический эффект.
* **🏷 Смена ника & Невидимка:** Мгновенно меняет отображаемое имя через WebSocket (`evt: 4147 / WS_CONF_RENAME_REQ`), обходя запрет хоста на переименование. Есть кнопка невидимого ника (Hangul Filler `\u3164`), кнопка быстрой смены на имя хоста и история последних ников.
* **🎭 Аватарки (Avatar Scanner):** Считывает реальный список участников из Redux Store. Компактный прокручиваемый список с настоящими аватарками. ЛКМ по карточке — копирует аватарку. ПКМ — подставляет ник в поле завесы. Двойной клик — мгновенно переименовывает вас в этого человека.
* **😃 Спам реакциями:** Отправляет эмодзи напрямую через внутренний сокет (`evt: 4103`) без открытия панели смайликов. Поддерживает сетку эмодзи и кастомный ввод.
* **✋ Спам рукой (Jumper):** Автоматически поднимает и опускает руку через `evt: 4131`. Скорость регулируется ползунком от 1 до 1000мс. При остановке гарантированно опускает руку через прямой сокет-запрос.
* **🕵️ Инспектор митинга:** Читает данные напрямую из Redux: Meeting ID, пароль, тему, имя хоста, количество участников и политики комнаты (заблокирован ли вход, разрешены ли аннотации, чат, переименование). Дополнительно извлекает **прямую ссылку-приглашение** (`join URL` с зашифрованным `pwd`) из DOM-элемента `.meeting-info-icon__meeting-url` или из адресной строки браузера как запасной вариант. Ссылка копируется в буфер одним кликом.
* **📡 Мониторинг активности:** Подписывается на `store.subscribe()` и в реальном времени логирует изменения: кто включил/выключил микрофон, камеру, поднял/опустил руку, зашёл/вышел.
* **🎨 Z-Art Studio (Принтер рисунков):** Встроенный векторный принтер аннотаций. Открывается кнопкой **«🎨 Принтер»** в навигационной панели виджета. Позволяет записывать штрихи вживую через прозрачный оверлейный холст, а затем автоматически воспроизводить их на холсте аннотаций Zoom. Можно вставить готовый JSON-массив штрихов и напечатать заранее нарисованную картинку. Поддерживает несколько инструментов (линия, стрелка, прямоугольник, эллипс, ластик), 10 цветов, регулировку скорости и группировку штрихов по инструменту и цвету для ускорения печати. Панель перетаскивается и скрывается/показывается без потери данных и введённого кода.

## 🎨 Интерфейс (UI)

Виджет оформлен в стиле **Glassmorphism** (полупрозрачный фон с blur-эффектом). Панель кнопок-вкладок сверху — каждая кнопка является переключателем, при клике показывает/скрывает соответствующую карточку-раздел. Несколько разделов можно держать открытыми одновременно. Виджет сворачивается в мини-полоску кнопкой в шапке. Перетаскивается за шапку в любую часть экрана.

## ⌨️ Горячие клавиши
| Хоткей | Название | Действие |
|---|---|---|
| **`Alt + S`** | **Мгновенная завеса** | Сразу задёргивает экран демонстрации чёрным слоем |
| **`Alt + D`** | **Корзина (Очистка)** | Очищает все слои аннотаций + возвращает оригинальный ник |
| **`Alt + Z`** | **Залп эмодзи** | Отправляет пакет из 30 реакций подряд |

## 🔄 Совместимость и обновления Zoom
1. **Устойчивые к обновлениям функции:** Инспектор митинга, список участников (Redux/React Fiber), завеса и очистка слоёв (DOM события) — стабильны при большинстве обновлений Zoom.
2. **Низкоуровневые функции сокетов** (смена ника, реакции, рука): используют Webpack-модули `MOD_SOCKET = 61142` и `MOD_EVENTS = 22371`. Если после обновления Zoom они перестали работать — найдите новые ID по инструкции в [`ARCHITECTURE.md`](./ARCHITECTURE.md).
